# ⚪ 오목 게임 (Gomoku Web Game) ⚫

웹 브라우저에서 바로 플레이할 수 있는 깔끔하고 직관적인 오목 게임입니다.

## ✨ 주요 기능
- **15x15 정통 오목판**: 화점 및 격자 표시, 부드러운 돌 그래픽
- **2가지 게임 모드**:
  - 🤖 **혼자 하기 (AI 대전)**: 스마트한 인공지능과 대결
  - 👥 **2인 대전**: 한 기기에서 두 명이 번갈아 대결
- **편의 기능**:
  - 한 수 무르기 (Undo)
  - 새 게임 시작
  - 직관적인 차례 표시 및 마지막 착수 위치 표시
  - 모바일 & PC 반응형 지원

## 🚀 플레이 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저에서 엽니다.

## 🌐 GitHub Pages로 웹 배포하기
이 저장소의 **Settings > Pages** 메뉴에서:
1. `Build and deployment`의 Source를 **Deploy from a branch**로 설정
2. Branch를 **main** / **/(root)** 로 선택 후 Save
3. 몇 분 후 `https://1jhzn.github.io/omok-game` 주소로 전 세계 어디서든 바로 접속하여 플레이할 수 있습니다!
