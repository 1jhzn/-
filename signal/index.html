⚙️ 안드로이드 크롬에서 자동 전체 스캔 켜는 법 ▼
블루투스 기기는 광고(advertisement) 신호를 계속 뿌립니다. 크롬은 기본 설정에서는 내가 목록에서 고른 기기에 대해서만 정보를 보여 주기 때문에, 주변 모든 신호를 한 번에 모으려면 다음 한 번의 설정이 필요해요. (설정을 하지 않아도 아래 스캔 시작 버튼은 기기 선택 창으로 동작합니다.)
  1. 크롬 주소창에 chrome://flags 입력
  2. 검색창에 Experimental Web Platform features 입력
  3. 오른쪽 값을 Enabled로 변경
  4. 아래쪽 Relaunch 버튼을 눌러 크롬 재시작
  5. 이 페이지로 돌아와 스캔 시작을 누르면 주변 신호가 자동으로 모입니다
되돌리려면 같은 항목을 Default로 바꾸고 다시 Relaunch 하면 됩니다. 블루투스와 위치(또는 근처 기기) 권한이 켜져 있어야 하고, 처음 한 번은 권한 창을 허용해 주세요.

    📶 주파수·대역 판별기

    숫자를 넣으면 어디에 쓰는 전파인지 알려 줘요. 단위를 비워 두면 알아서 맞춰요.

    🔎 이렇게 쓰여요

    우리 주변에는 눈에 보이지 않는 전파가 아주 많아요. 그중에서도 위쪽 감지기가 실제로 잡는 것은 블루투스 LE(2.4GHz) 광고 신호예요. 와이파이나 휴대폰 기지국은 이 웹앱이 직접 잡을 수 없지만, 주파수를 넣어 어떤 용도인지 확인할 수는 있어요.

    🧭 이 앱이 하는 일

    주변에서 뿌려지는 블루투스 LE 광고 신호를 읽어서 ① 어떤 신호가 새로 나타났는지, ② 그 신호가 어디서 나온 것인지(제조사·기기 종류·대략적인 거리)를 알려 줍니다. 신호 세기(RSSI)로 거리를 어림하고, 제조사 ID·서비스 UUID·기기 이름·광고 데이터를 함께 살펴 판별해요.

    ✅ 지원 환경

    안드로이드 크롬에서 가장 잘 동작해요. 아이폰 사파리는 웹에서 블루투스를 쓰는 기능을 제공하지 않아 이 앱을 쓸 수 없어요. 컴퓨터 크롬은 블루투스 어댑터가 있는 경우에만 일부 동작해요.

    전체 자동 스캔은 chrome://flags의 실험 기능을 켜야 하고, 끈 상태에서는 크롬이 띄워 주는 기기 선택 창에서 고른 기기만 볼 수 있어요. 어느 쪽이든 기준 저장 → 새 신호 알림은 똑같이 동작합니다.

    ⚠️ 알아 둘 점

    · 거리는 신호 세기로 계산한 어림값이에요. 벽이나 사람 몸, 기기 각도에 따라 크게 달라져요.
    · 블루투스 기기는 주소를 자주 바꾸기 때문에, 같은 기기가 잠깐 새 신호처럼 잡힐 수 있어요.
    · 앱은 신호를 읽기만 하고, 상대 기기에 연결하거나 내용을 바꾸지 않아요(직접 누른 ‘상세 정보 읽기’ 제외).
    · 와이파이, 휴대폰 기지국, 라디오 전파는 브라우저에서 잡을 수 없어요.

    🔒 개인정보

    감지한 신호와 기준 목록은 이 휴대폰 안(localStorage)에만 저장되고 어디로도 전송되지 않아요. 서버도, 로그인도, 광고도 없습니다. 목록 비우기나 기준 지우기로 언제든 지울 수 있어요.

    🛠 만든 방식

    웹 표준(Web Bluetooth / Web Audio / Canvas)만 사용해 처음부터 직접 만든 페이지예요. 제조사 ID와 서비스 UUID는 블루투스 표준(SIG)에 공개된 식별 번호를 바탕으로 정리했습니다.
